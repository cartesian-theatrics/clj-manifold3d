Quick reference & limits

m, texture, animation, and math are ready to use. Explicit require is supported for these namespaces.

The editor highlights ClojureScript, auto-closes brackets and string quotes, and indents with Tab. Run with Ctrl/Cmd+Enter.

Return a Manifold, CrossSection (shown 1 unit thick), animation scene, or {:geometry solid :texture png-bytes}. Try m/loft, m/difference, m/color, or texture/geodesic-uv.

texture/bake turns opaque, colored geometry into PNG bytes, viewed from +Z. The flag example draws its artwork in code, then maps it to a stepped-out sphere patch.

Frame rotations use radians; solid rotations use degrees. (math/sin x) and math/pi are available.

SCI interprets a CLJS subset, not the full CLJS compiler. Arbitrary JS, npm packages, and asset/file I/O aren’t exposed. Each Run starts a fresh context, releases its native handles, and has a 30-second timeout. Stop terminates the worker; the last good model stays visible.
