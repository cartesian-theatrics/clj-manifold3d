# Raptor 3 SN1

A detailed, photo-based exterior model of the August 2024 sea-level Raptor 3.
Every engine and transport-fixture mesh is generated by `clj-manifold3d` in
[`raptor_3.clj`](raptor_3.clj). No imported engine meshes or external texture files.

```sh
clojure -M:clj-dev -m raptor-3 target/raptor-3.glb
# Lower tessellation, without the transport pallet and braces:
clojure -M:clj-dev -m raptor-3 target/raptor-3-engine.glb draft no-stand
```

The checkout's normal JVM native bindings are required (see the root README).
Load the GLB in a glTF viewer or Blender. It includes named components,
PBR materials, smooth normals with sharp mechanical edges, a separate removable
transport group, and a metre-scale Y-up root. Geometry helpers use millimetres,
with the nozzle exit at Z=0. Require `[raptor-3 :as r]` and call `(r/assembly)`
to use the scene from a REPL; `(r/engine-parts)` returns the unscaled solids.
The namespace has no load-time modeling or file-writing side effects.

The [browser journal](https://cartesian-theatrics.github.io/clj-manifold3d/journal/)
includes **Raptor 3 · engine**, a six-stage editable walkthrough generated from
this same source. Select it in the library and choose **Run page**. Its final
preview and GLB download use Z-up to match the journal viewer; the standalone
command above exports Y-up. Existing browser workspaces receive this new example
automatically on reload.

Features include a continuous hollow bell and chamber throat, a warm inner
liner, collector rings, casing welds, asymmetric pump housings, swept feed and
return plumbing, service covers, hex fasteners and washers, small valve lines,
a corrugated harness, attachment lugs, and a curved geometric SN1 stencil.
Deterministic fine-grain finish textures are generated in Clojure and embedded
in the GLB on the dark jacket and cast housings.
The fixture has hollow forklift runners, padded supports, and braced turnbuckles.

The default scene is approximately 2.73 m tall above the nozzle exit and 1.30 m
across the exit. These are modeling choices, not verified Raptor 3 dimensions.
Rear-side routing, small fittings, wall thicknesses, and concealed shapes are
interpretations. This is an exterior display assembly, not production CAD,
a flow simulation, or one fused printable solid. Named components may intersect
at their mechanical joints; each individual component is a closed solid.

Optional studio preview (Blender 4.2; only imports the model and adds lighting,
a floor, and a camera):

```sh
blender -b -t 8 --python examples/raptor_3_render.py -- target/raptor-3.glb target/raptor-3.png
```

This writes a PNG and a `.blend` scene beside it. The exported GLB itself has
no studio floor or lights. Use environment lighting to see the metal finishes.

The exporter checks native status and positive volume for every component.
Focused checks also verify the nozzle bore, stencil visibility, curved sweeps,
fixture omission, and metre scaling:

```sh
clojure -M:clj-dev -e '(load-file "test/clj/clj_manifold3d/raptor_3_test.clj") (let [r (clojure.test/run-tests (quote clj-manifold3d.raptor-3-test))] (System/exit (if (clojure.test/successful? r) 0 1)))'
```
